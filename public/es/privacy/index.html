Política de privacidad

Datos de la aplicación

La aplicación guarda los ajustes y tus mejores resultados en el dispositivo. No tiene cuentas de Stampost, publicidad, seguimiento ni herramientas de análisis. La aplicación no envía estos registros a ipe studio.

Datos del sitio web

El juego web recuerda el idioma, la mejor puntuación y la calificación por estrellas en el navegador. Para eliminarlos, borra los datos de este sitio en el navegador. El sitio no tiene anuncios ni herramientas de análisis. GitHub Pages aloja el sitio y registra las direcciones IP de los visitantes por motivos de seguridad.

Asistencia y tiendas

Si escribes a asistencia, ipe studio utiliza tu dirección de correo y lo que nos envíes para responderte. Usa el mismo contacto para consultas sobre privacidad. Apple y Google gestionan las descargas con arreglo a sus propias políticas de privacidad.
